# 仓库管理系统操作手册

## 1. 登录

1. 打开公司地址，例如 `https://acme.wms.tangzheheshui.cn/`。
2. 登录页显示系统名「万顺WMS仓库管理系统」和本公司名称；输入姓名全拼和密码。
3. 首次登录必须修改初始密码。

密码规则：8-20 位，必须同时包含字母和数字。连续 5 次失败会锁定 10 分钟。

## 2. 万顺控制台（平台管理员）

控制台地址 `https://console.wms.tangzheheshui.cn/`，仅供万顺平台管理员使用，管理公司租户，不进入公司业务系统。

### 2.1 创建公司

路径：`公司管理 -> 新建公司`

| 字段 | 说明 |
| --- | --- |
| 公司前缀 | 子域名与数据目录，2-32 位小写字母/数字/连字符，不可与保留字（console、www 等）或已有公司重复 |
| 公司名称 | 显示在该公司登录页系统名下方；公司管理员后续可自行修改 |
| 订阅时长 | 1/2/3 年，默认 1 年；到期日 = 当天 + 时长，到期后该公司不可访问 |
| 订单金额 / 订单备注 | 选填，登记客户线下收款信息（如 `3980`、`2026年度订阅`） |

管理员账号固定为 `admin`（显示名「管理员」），无需手动命名。保存后**一次性显示** admin 初始密码和公司访问地址，请立即转交该公司；关闭后无法再次查看。新公司子域名立即可访问。开通即生成首笔订阅订单。

### 2.2 管理公司

公司列表支持：

- **订阅/续费**：进入公司详情页，可查看订阅到期日（徽标：正常 / 即将到期剩 N 天 / 已到期 / 永久）和全部订单记录（单号、下单时间、时长、起止、金额、备注、操作人）；续费时选时长并登记金额备注。未到期续费在到期日基础上顺延，已到期续费从当天重算，续费后立即恢复访问。订单仅作人工登记，不对接支付。
- **到期阻断**：订阅到期后该公司全部子域名显示「订阅已到期」提示页，续费后自动恢复；未登记订阅的存量公司视为永久有效。
- **停用/启用**：停用后该公司全部子域名显示「已停用」提示页，数据完整保留；启用后恢复访问。
- **重置公司管理员密码**：应急通道（公司管理员忘记密码时使用）。重置后旧密码与登录态全部失效，新初始密码一次性显示，首次登录强制修改。

平台管理员首次登录控制台会强制修改初始密码；控制台内也可随时修改密码。

## 3. 管理员初始化

公司管理员登录公司系统后，先在「系统设置」确认公司名称，再按下面章节初始化基础数据。公司内部用户（含更多公司管理员）由公司管理员在「用户管理」中创建、授权、重置密码、停用；万顺不介入。

### 3.1 录入商品

路径：`商品信息 -> 录入商品`

填写货品编号、货品名称、货品分类、规格、单位、单件重量、体积、保质天数。货品编号公司内唯一，所有项目共用。保存后需在“项目管理 -> 项目可用商品”中把商品添加到项目，才能进行出入库。

### 3.2 维护仓库

路径：`仓库信息 -> 新增仓库`

先创建仓库，再填写库区、货区、货位。完整货位显示为：

```text
仓库 / 库区 / 货区 / 货位
```

### 3.3 创建项目

路径：`项目管理 -> 创建项目`

创建项目时需绑定唯一的仓库和库区，项目管理员只能在绑定仓库/库区内作业。项目名称公司内唯一，库存、单据、模板和日志都按项目隔离。

### 3.4 创建项目管理员

路径：`用户管理 -> 创建项目管理员`

填写：

| 字段 | 说明 |
| --- | --- |
| 姓名 | 页面显示的中文名 |
| 姓名全拼 | 登录用户名，例如 `zhangsan` |
| 手机号 | 联系方式，不用于登录 |
| 初始密码 | 8-20 位，含字母和数字 |
| 授权项目 | 至少选择一个项目 |

后续可在用户列表中修改授权、重置密码、停用账号。

## 4. 导入历史库存

由系统管理员执行，仅适用于没有库存的新项目。

路径：`项目管理 -> 项目列表 -> 导入历史库存`

上传提供的库存明细 CSV。系统会：

1. 自动创建 CSV 中不存在的商品、仓库和货位。
2. 保留库存总数、分拣占用数、移动占用数、品质标记、禁止出库等信息。
3. 生成一张历史导入单和库存流水。
4. 忽略 CSV 的可用库存列，由系统重新计算。

历史库存只能对一个空项目导入一次。

## 5. 项目管理员作业

登录后可在右上角切换已授权项目。

### 5.1 入库

路径：`入库管理 -> 下载模板`

填写模板后点击“上传校验并入库”，也可在页面“手动新增入库”逐条录入。模板必填字段：入库通知单号、入库日期、货品编号、生产批号、生产日期、数量、单位、货位；品质标记默认为良品；到期日期留空时由生产日期加商品保质天数自动计算。仓库、库区由项目自动关联，无需填写。

任何一行错误，整单都不会入库；页面显示 Excel 行号、列名和错误原因。

### 5.2 出库

路径：`出库管理 -> 下载模板`

填写配货单号、出库日期、货品编号、数量、单位后上传，也可在页面“手动新增出库”逐条录入。品质默认良品；生产批号、生产日期可筛选批次；指定货位留空时按先进先出自动分配，填写时仅从该货位出库。

系统按当前项目可用库存校验：

```text
可用库存 = 库存总数 - 分拣占用数 - 移动占用数
```

出库成功后立即扣减库存，按入库日先进先出分配批次，并生成拣货单。扣留或禁止出库的批次不能出库。

### 5.3 移库

路径：`移库管理 -> 下载模板`

在同一项目的仓库库区内，把某商品某批次从源货位移动到目标货位。模板必填字段：移库单号、移库日期、货品编号、生产批号、数量、单位、源货位、目标货位；也可在页面“手动新增移库”逐条录入，货品、批次和货位输入框会联想当前项目已有库存。

提交通过校验后立即生效：源货位扣减、目标货位增加。目标货位已有同商品同批次库存时，生产日期、到期日期、入库日、品质、采购单号须与源批次一致才能合并，否则整单拒绝。可用库存不足、源目标货位相同、货位不存在或不在项目库区内都会整单拒绝。移库后源货位库存为 0 时保留 0 库存行；扣留、禁止出库的批次允许移库，标记随批次带到目标货位。

### 5.4 拣货

路径：`拣货单`

选择拣货单后可查看明细、打印 A4、导出 Excel。打印和导出支持“按货位排序”或“按货品编号排序”两种方式；内容过多时自动分页并标注页码（如 1-1、1-2）。表头包含分拣组号、出库通知单号、出货日期、收货方。实际拣货完成后点击“拣货完成”。

库存在上传出库单时已扣减，点击拣货完成只更新作业状态，不会重复扣减。

## 6. 库存查询

路径：`库存查询`

支持按仓库、库区、货区、货位、货品、生产批号、品质标记、禁止出库查询。页面提供“库存汇总”（按货品编号聚合）和“库存明细”（按货位展开）两个视图，可自定义显示/隐藏列，并导出当前视图的 Excel。

查询结果不保存历史记录，需要时重新查询或导出。

## 7. 模板管理

路径：`模板管理`

项目管理员可修改当前项目的中文列名、非系统必填字段和启用状态。保存后版本号加一，历史单据仍记录当时版本。

停用模板后不能下载和导入，不影响历史数据。

## 8. 操作日志

路径：`操作日志`

项目管理员可查看当前项目的入库、出库、移库、拣货完成、模板变更、历史导入等日志。日志不可修改或删除。

## 9. 日常巡检

V5 平台模式下统一巡检 `wms-platform` 单进程：

```bash
ssh ubuntu@193.112.26.217
systemctl status wms-platform --no-pager
journalctl -u wms-platform -n 100 --no-pager
sudo nginx -t
```

备份公司数据库（平台模式，按公司前缀）：

```bash
sudo sqlite3 /opt/wms-platform/data/companies/acme/warehouse.db \
  ".backup '/opt/wms-platform/data/companies/acme/backup-manual.db'"
```

公司注册表 `data/platform.json` 也建议随数据库一起备份。

## 10. 常见问题

| 问题 | 处理 |
| --- | --- |
| 忘记密码（公司内部用户） | 公司管理员在用户管理中重置 |
| 忘记密码（公司管理员） | 联系万顺，由平台管理员在控制台重置 |
| 上传失败 | 检查 `.xlsx`、5MB、500 行、模板表头 |
| 提示库存不足 | 查看批次明细中的可用库存，不是库存总数 |
| 不能进入某项目 | 让管理员检查用户授权 |
| 项目无法作业 | 检查项目是否停用 |
| 公司子域名显示「已停用」 | 公司被万顺停用，联系平台管理员启用 |
| 公司子域名显示「公司不存在」 | 检查访问地址的前缀是否正确 |
