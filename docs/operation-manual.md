# 仓库管理系统操作手册

本文包含部署、初始化、日常出入库、拣货、库存查询、账号管理和常见问题处理。

## 1. 部署前确认

部署使用 `193.112.26.217`，SSH 用户固定为 `ubuntu`。先确认：

```bash
ssh ubuntu@193.112.26.217
```

能登录即可。腾讯云安全组放行 `22` 和 `80`。

## 2. 一键部署

在本机打开终端，执行：

```bash
cd /Users/feng/code/warehouse-management-system
COMPANY_NAME="Acme" WMS_ADMIN_PHONE=你的手机号 ./deploy.sh default 193.112.26.217
```

`COMPANY_NAME` 必填，使用英文公司名。`default` 是实例标识，决定服务器目录和服务名。

首次部署时，脚本会在终端显示一次随机初始密码，请立即记录并在首次登录后修改。

部署成功后访问：

```text
http://193.112.26.217/
```

## 2.1 部署第二家公司

每家公司独立目录、数据库、管理员和服务。第二家公司必须换实例标识和端口：

```bash
APP_PORT=8001 PUBLIC_PORT=8081 COMPANY_NAME="Beta" WMS_ADMIN_PHONE=第二个公司管理员手机号 ./deploy.sh beta 193.112.26.217
```

访问：

```text
http://193.112.26.217:8081/
```

腾讯云安全组需要额外放行 `8081`。

## 3. 首次登录

1. 打开 `http://193.112.26.217/`
2. 输入管理员手机号和初始密码
3. 系统强制进入修改密码页
4. 设置新密码：8-20 位，必须同时包含字母和数字
5. 修改成功后进入工作台

管理员默认拥有全部权限，包括入库、出库、拣货、库存查询、用户管理、模板管理和操作日志。

## 4. 创建仓库人员账号

管理员操作路径：

```text
用户管理 -> 新增用户
```

填写手机号、角色和初始密码。角色选择“仓库人员”。仓库人员首次登录也会被强制修改密码。

### 重置密码

路径：

```text
用户管理 -> 重置密码
```

输入新初始密码后，该用户下次登录必须重新修改密码。当前版本不支持短信验证码找回密码，忘记密码由管理员重置。

### 禁用账号

路径：

```text
用户管理 -> 禁用
```

禁用后该账号立即无法登录。需要恢复时点击“启用”。

## 5. 维护 Excel 模板

管理员操作路径：

```text
模板管理
```

系统内置入库模板和出库模板。

### 下载模板

```text
模板管理 -> 下载当前模板
```

也可以进入入库或出库页面点击“下载模板”。模板第二行是示例行，上传时自动忽略。

### 修改列配置

```text
模板管理 -> 修改 Excel 列名 -> 保存并生成新版本
```

可修改 Excel 列名和非系统必需字段是否必填。商品ID、商品名称、数量为系统必需字段；入库模板的批次号、库位也是系统必需字段。

每次保存后版本号自动加一。历史单据会继续记录当时使用的模板版本号。

### 停用模板

```text
模板管理 -> 停用模板
```

停用后不能下载该模板，也不能继续上传该类型导入文件；历史单据和库存流水不受影响。

## 6. 入库操作

适用角色：管理员、仓库人员。

### 第一步：下载模板

```text
入库管理 -> 下载模板
```

### 第二步：填写 Excel

默认入库列：

| 列名 | 是否必填 | 说明 |
| --- | --- | --- |
| 商品ID | 是 | 不存在时自动建档 |
| 商品名称 | 是 | 已建档商品必须与档案一致 |
| 规格 | 否 | 建议填写 |
| 批次号 | 是 | 同商品同批次同库位会累计数量 |
| 生产日期 | 否 | 格式 `yyyy-MM-dd` |
| 保质期（天） | 否 | 正整数 |
| 数量 | 是 | 正整数 |
| 库位 | 是 | 例如 `A-01-01` |
| 备注 | 否 | 文本 |

单次最多 500 行，文件不能超过 5MB。

### 第三步：上传入库

```text
入库管理 -> 选择文件 -> 上传校验并入库
```

校验通过后系统生成入库单、增加库存、写入库存流水和操作日志。入库单状态为“已完成”。

### 校验失败

任何一行错误，整单都不会入库。页面会显示 Excel 行号、列名和错误原因，可点击“下载错误明细”导出 Excel，修正后重新上传。

## 7. 出库操作

适用角色：管理员、仓库人员。

### 第一步：下载模板

```text
出库管理 -> 下载模板
```

### 第二步：填写 Excel

默认出库列：

| 列名 | 是否必填 | 说明 |
| --- | --- | --- |
| 商品ID | 是 | 必须已存在 |
| 商品名称 | 是 | 必须与商品档案一致 |
| 规格 | 否 | 填写后必须与档案一致 |
| 数量 | 是 | 正整数 |
| 备注 | 否 | 文本 |

出库单不需要填写批次号和库位。

### 第三步：上传出库

```text
出库管理 -> 选择文件 -> 上传校验并出库
```

系统会校验商品和库存，通过后立即扣减库存，按“先入库先出”分配批次，并自动生成拣货单。

同一商品多行会合并数量校验。库存不足时提示：

```text
当前商品库存为X件，出库数量Y件，库存不足无法出库
```

任何一行校验失败，整单不出库、不扣库存、不生成拣货单。

## 8. 拣货作业

路径：

```text
拣货单
```

出库成功后自动生成一张拣货单。拣货明细包含库位、商品ID、商品名称、规格、批次号和数量，并按库位排序。

### 打印拣货单

```text
拣货单 -> 选择单据 -> 打印A4
```

打印页只输出拣货单内容，不输出系统导航。

### 导出拣货单

```text
拣货单 -> 导出Excel
```

### 确认拣货完成

仓库人员按单拣货后点击“拣货完成”。确认后拣货单和关联出库单都会变为“已完成”。

注意：库存在出库上传成功时已经扣减，拣货完成只更新作业状态，不会再次扣库存。

## 9. 查询库存

路径：

```text
库存查询
```

支持商品ID、商品名称、批次号和库位查询。页面提供三层信息：

1. 商品汇总：库存总量、库位列表
2. 批次明细：批次、库位、数量、最近入库时间
3. 库存流水：出入库单号、批次、库位、数量变动、操作人、时间

填写商品ID后查询，库存流水会按该商品精确过滤。

### 导出库存

```text
库存查询 -> 导出Excel
```

导出内容为当前查询条件下的批次明细。

## 10. 查询单据

入库单路径：

```text
入库管理 -> 入库单
```

出库单路径：

```text
出库管理 -> 出库单
```

支持按单号、操作人、开始日期和结束日期查询。

## 11. 查看操作日志

仅管理员可查看。

```text
操作日志
```

日志记录用户变更、入库、出库、模板变更和拣货完成。当前版本不支持删除日志。

## 12. 修改密码

```text
右上角 -> 修改密码
```

规则：8-20 位、必须包含字母和数字、新旧密码不能相同。修改成功后，同一账号在其他设备上的登录状态会被退出。

## 13. 日常巡检

登录服务器：

```bash
ssh ubuntu@193.112.26.217
```

查看服务状态：

```bash
systemctl status wms --no-pager
```

查看实时日志：

```bash
journalctl -u wms -f
```

检查健康接口：

```bash
curl http://127.0.0.1:8000/api/health
```

检查 Nginx：

```bash
sudo nginx -t
systemctl status nginx --no-pager
```

## 14. 数据备份

手动备份：

```bash
sudo mkdir -p /opt/wms/data/backups
sudo sqlite3 /opt/wms/data/warehouse.db ".backup '/opt/wms/data/backups/manual-$(date +%Y%m%d-%H%M%S).db'"
```

建议同时在腾讯云控制台开启服务器快照，并将备份定期复制到服务器之外。

## 15. 升级版本

在本机项目目录执行：

```bash
cd /Users/feng/code/warehouse-management-system
COMPANY_NAME="Acme" WMS_ADMIN_PHONE=你的手机号 ./deploy.sh default 193.112.26.217
```

脚本会先备份服务器现有数据库，再上传新代码、重启服务并执行测试。升级其他公司实例时，继续使用原来的公司和端口参数：

```bash
APP_PORT=8001 PUBLIC_PORT=8081 COMPANY_NAME="Beta" WMS_ADMIN_PHONE=该公司管理员手机号 ./deploy.sh beta 193.112.26.217
```

## 16. 常见问题

### 打不开网站

1. 检查腾讯云安全组是否放行 80 端口
2. 登录服务器执行：

```bash
systemctl status wms --no-pager
systemctl status nginx --no-pager
```

3. 如果 `wms` 未运行，查看原因：

```bash
journalctl -u wms -n 100 --no-pager
```

### 忘记管理员密码

需要有另一个管理员账号重置。如果只有一个管理员且密码丢失，需要登录服务器手工处理数据库，处理前必须先备份数据库。

### 上传 Excel 失败

检查：

1. 文件后缀必须是 `.xlsx`
2. 文件不能超过 5MB
3. 数据不能超过 500 行
4. 表头必须与当前启用模板一致
5. 模板是否已被管理员停用

### 出库提示库存不足

在库存查询页确认该商品库存总量。系统按同一商品所有批次、所有库位合计校验。

### 页面显示“请先修改初始密码”

这是首次登录或管理员刚重置密码后的正常安全策略。修改密码后即可使用系统。
