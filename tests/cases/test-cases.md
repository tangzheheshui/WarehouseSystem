# 仓库管理系统测试用例

## 1. 说明

- 优先级：P0 最高，P3 最低。
- 自动化状态分为：已自动化、待自动化、只适用生产冒烟。
- 所有破坏性用例只能使用临时数据库，禁止在 `acme` 生产库执行。
- `zhangsan` 是临时库自动创建的管理员，`liuhaifeng` 是临时库自动创建的项目管理员；两者不是外部环境依赖。
